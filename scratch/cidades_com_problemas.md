## Scripts utilizados

| Script | Função |
|---|---|
| `analyze_gpkg_cities.py` / `analyze_gpkg_cities_to_file.py` | Detecta nomes que não correspondem à lista oficial |
| `generate_updates_list.py` | Gera automaticamente o `update_gpkg_all.py` |
| `update_gpkg.py` | Versão inicial (só RJ + poucos estados) |
| `update_gpkg_all.py` | Script completo — aplica todas as 176 correções |
| `update_gpkg_dynamic.py` | Versão alternativa com matching dinâmico |
| `backup_files.py` | Faz backup dos GPKGs antes de modificar |
| `find_campos.py` | Verifica a situação do Campos dos Goytacazes especificamente |
| `inspect_unresolved.py` | Investigação de casos sem correspondência automática |
